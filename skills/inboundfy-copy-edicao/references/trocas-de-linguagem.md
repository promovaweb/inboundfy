# Trocas de linguagem

Leia no passo 5 do fluxo. A tabela lista expressões que deixam o texto
vago, inflado ou corporativo, com uma troca em português direto. A troca
sugerida é ponto de partida: quase sempre a melhor correção é reescrever a
frase com o objeto, o ator e a consequência reais.

Esta lista não substitui `.inboundfy/context/proibicoes.md` nem
`.inboundfy/context/estruturas-proibidas.md`. Quando uma expressão estiver
nesses arquivos, ela reprova o texto. As demais são sinais para revisar.

## Verbos inflados

| Evite | Prefira | Observação |
| --- | --- | --- |
| otimizar processos | nomeie o processo e o ganho: "fechar o caixa em 10 minutos" | O verbo sozinho não diz o que melhora. |
| maximizar resultados | diga qual resultado e quanto | Sem número, corte. |
| impulsionar vendas | "vender mais para quem já comprou" ou o mecanismo | |
| viabilizar | permitir, fazer funcionar | |
| implementar | colocar em uso, instalar, configurar | Mantenha em contexto técnico de software. |
| disponibilizar | oferecer, liberar, enviar | |
| agregar valor | diga o que a pessoa ganha | |
| endereçar (um problema) | resolver, tratar | Anglicismo. |
| performar | render, funcionar, vender | |
| entregar valor | entregar o quê? nomeie | |

## Substantivos abstratos

| Evite | Prefira |
| --- | --- |
| solução | o nome do produto ou o que ele faz ("emissor de nota", "agenda online") |
| plataforma robusta | o que ela aguenta: "3 mil pedidos por dia sem travar" |
| ecossistema | o conjunto real: "app, painel e integração com o banco" |
| gestão inteligente | a regra que o sistema aplica sozinho |
| experiência do cliente | o momento concreto: "atendimento no WhatsApp", "entrega" |
| sinergia | corte ou descreva a colaboração |
| expertise | experiência, anos de trabalho com X |
| know-how | experiência prática em X |

## Adjetivos sem prova

| Evite | O que fazer |
| --- | --- |
| inovador, revolucionário, disruptivo | Mostre o que é diferente e por que importa. |
| completo, integrado | Liste o que está incluso, ou o que conversa com o quê. |
| líder de mercado, referência | Só com fonte; caso contrário, corte. |
| fácil, simples, intuitivo | Mostre: "você configura em 15 minutos", "3 cliques". |
| personalizado | Diga o que muda para cada cliente. |
| de alta qualidade | Mostre o controle, o material, a garantia. |

## Muletas de frase

| Evite | Prefira |
| --- | --- |
| "É importante ressaltar que X" | "X" |
| "Nos dias de hoje" | corte ou cite a mudança concreta e a data |
| "Com isso em mente" | corte |
| "Ou seja," repetido | uma vez por texto, no máximo |
| "A fim de" | para |
| "Através de" (meio) | por, com, pelo |
| "No que diz respeito a" | sobre, em |
| "Realizar uma análise" | analisar |
| "Fazer a gestão de" | gerir, cuidar de, controlar |
| "Estamos à disposição" | diga o canal e o prazo: "responda este email ou chame no WhatsApp" |

## Anglicismos com troca natural

Mantenha o termo em inglês quando ele é o nome usado pela persona (lead, CRM,
dashboard, checkout). Troque quando houver palavra comum em português.

| Evite | Prefira |
| --- | --- |
| deadline | prazo |
| feedback (para cliente final) | opinião, retorno, avaliação |
| budget | orçamento, verba |
| case | caso, exemplo de cliente |
| insight | percepção, descoberta, conclusão |
| call | reunião, ligação |
| follow-up | retorno, acompanhamento |

## Como aplicar

1. Marque as ocorrências na passagem 2 (clareza) ou 6 (especificidade).
2. Para cada uma, pergunte: qual objeto, ator ou número esta palavra
   esconde?
3. Se a resposta existe na fonte, reescreva a frase com ela.
4. Se não existe, corte a frase ou registre a pendência.
5. Não troque por sinônimo da mesma família: "maximizar" por
   "turbinar" continua vazio.
