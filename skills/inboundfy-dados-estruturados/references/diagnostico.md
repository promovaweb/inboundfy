# Diagnóstico de dados estruturados

No passo 2, responda e registre as respostas no artefato:

1. Qual o assunto principal da página: empresa, unidade, artigo, produto,
   evento, aplicativo, vídeo, curso?
2. Que fatos aparecem visíveis na página e qual arquivo de contexto confirma
   cada um?
3. O site já gera marcação por plugin, tema ou framework? Ela vai conviver ou
   ser substituída?
4. Que resultado aprimorado o Google exibe hoje para esse tipo de página e
   para quais sites ele está disponível?
5. Preço e estoque mudam com frequência? Quem atualiza?
6. A página tem avaliações reais de clientes coletadas nela?
7. Como o código chega ao site: campo do CMS, plugin, modelo do tema,
   componente do framework?
