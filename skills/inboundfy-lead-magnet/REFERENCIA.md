# Referência de material rico

## Ficha

```md
persona:
tarefa:
resultado:
formato:
promessa:
escopo:
fontes:
cta:
entrega:
sequência_posterior:
```

O recurso deve resolver uma tarefa delimitada. Se a promessa depende de
consultoria, ferramenta externa ou informação que não foi entregue, isso deve
aparecer antes do cadastro.
