# Referência de copywriting

## Brief mínimo

```md
objetivo:
canal:
formato:
persona:
acervo:
oferta:
cta:
ângulo:
restrições:
```

## Perguntas para o texto

1. O que a pessoa precisa entender agora?
2. Qual mudança concreta a oferta ajuda a produzir?
3. Qual detalhe do acervo torna a mensagem específica?
4. Qual dúvida impede o próximo passo?
5. Qual ação cabe neste momento da jornada?

## Adaptação multicanal

Uma ideia pode gerar peças diferentes, mas cada peça precisa de um propósito
próprio. Blog aprofunda e organiza busca; email conduz uma conversa; LinkedIn
abre uma tese profissional; Instagram privilegia leitura rápida e sequência;
Substack desenvolve uma visão; YouTube organiza fala, cena e retenção.
