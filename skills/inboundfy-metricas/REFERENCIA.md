# Referência de métricas

## Ficha

```md
pergunta_de_negócio:
resultado_principal:
sinais_intermediários:
medidas_de_qualidade:
evento:
propriedades:
fonte:
janela:
responsável:
limites:
```

## Boa leitura

Apresente fonte, período, segmento, definição, mudança observada e ação
proposta. Não use porcentagem sem base absoluta nem taxa sem denominador.
