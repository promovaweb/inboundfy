# Referência de SEO

## Ficha de busca

```md
tema:
persona:
intenção:
termo principal:
variações:
entidades:
perguntas:
oferta relacionada:
cta:
páginas internas:
fontes:
```

## Auditoria

Verifique descoberta, intenção, título, descrição, URL, headings, abertura,
profundidade, links internos, dados estruturados quando aplicável,
acessibilidade textual, velocidade quando houver dados e atualização das
fontes. O relatório deve separar observação, impacto e ação.
