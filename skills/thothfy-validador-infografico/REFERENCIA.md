# REFERENCIA.md — thothfy-validador-infografico

Use o template de `thothfy-base-validador` com a produtora
`thothfy-especialista-infografico`.

## Checklist específico

- [ ] Todo número possui fonte rastreável e vigente.
- [ ] Cada bloco funciona isoladamente e na sequência.
- [ ] A legenda pública alcança 90%.
- [ ] O alt text descreve o conteúdo, sem repetir apenas o título.
- [ ] FAB aparece quando o infográfico apresenta produto.

## Exemplo fictício

Se um percentual não aponta fonte, reprove o bloco, cite o dado e devolva à
produtora para remover ou documentar a evidência.

## Erros comuns

Confundir texto curto de bloco com licença para publicar dado sem contexto.
