# Fontes e pesquisa de público

Referência para transformar material de pesquisa em persona. Lida no passo 2
do fluxo quando a entrada é material de pesquisa ou quando faltam dados para
os campos obrigatórios.

## Fontes por campo

| Fonte | Campos que alimenta melhor | Cuidado |
| --- | --- | --- |
| Entrevista com cliente | contexto de compra, dor, tentativas, gatilho | cinco a oito entrevistas por persona costumam revelar o padrão |
| Conversas de WhatsApp e tickets de suporte | jargão, objeção, dor | anonimizar antes de copiar trechos (LGPD) |
| Avaliações públicas (loja de aplicativos, Google, Reclame Aqui) | dor, objeção, jargão | é a voz de quem já comprou ou desistiu |
| Time comercial | objeção, gatilho, contexto de compra | registrar como observação do time |
| Formulário de cadastro ou questionário | quem é, porte, canal de origem | resposta curta, pouca profundidade |
| Buscas internas do site e termos de busca orgânica | jargão | mostra a palavra usada, não o motivo |
| Comentários em redes e grupos | jargão, dúvidas | amostra enviesada para quem comenta |

## Níveis de confiança

| Nível | Quando usar | O que a copy pode fazer |
| --- | --- | --- |
| Pesquisa com clientes | entrevistas ou dados de clientes reais analisados | usar a fala como base de título e argumento |
| Observação do time | percepção do comercial ou do suporte | usar como hipótese de ângulo, testar |
| Hipótese | sem dado, só intenção | usar só em rascunho; pedir validação |

## Roteiro curto de entrevista com cliente

Para quando o usuário quiser validar a persona. A condução completa fica com
`inboundfy-pesquisa-cliente`.

1. "Me conta como era antes de usar a gente. Como você fazia?"
2. "O que aconteceu logo antes de você procurar outra forma?"
3. "O que mais você considerou? Por que não escolheu?"
4. "O que quase fez você desistir?"
5. "Como você explicaria o que mudou para uma colega?"

Perguntas sobre o passado concreto rendem mais do que perguntas sobre
preferência ("você usaria...?").

## Cuidados com dados pessoais

- Persona não leva nome, telefone ou foto de cliente real.
- Trecho de conversa usado como jargão é anonimizado.
- Fala que vai virar prova social pública segue para
  `inboundfy-contexto-depoimentos`, com consentimento.

## Erros comuns

- Juntar respostas de perfis diferentes numa persona média que não existe.
- Tratar os comentários mais barulhentos como a voz de toda a base.
- Copiar trechos de conversas com nome do cliente para o arquivo.
