# Primeiro pedido

> Transforme esta ideia em um pacote para blog: como perceber que a bicicleta
> urbana precisa de revisão antes de um trajeto diário.

## Roteamento esperado

1. `thothfy-brainstorm` executa as fases `00–04`.
2. `thothfy-iniciar` executa planejamento `00–06`.
3. `thothfy-planejamento-05-producao` chama
   `thothfy-especialista-blog`.
4. A produtora envia o artigo a `thothfy-validador-blog`.
5. A auditoria consolida somente a versão aprovada.
