# Changelog

As mudanças relevantes do Inboundfy são registradas neste arquivo. A versão do
framework, do CLI, do pacote npm, da tag Git e da GitHub Release é sempre a
mesma.

## 1.1.0 (2026-09-13)

### Funcionalidades

- Separa método instalado em `.inboundfy/framework/` da configuração e dos
  dados vivos do projeto.
- Adiciona acervo numerado com bruto, processado, FAQ, base editorial,
  pesquisa e estratégia de reaproveitamento.
- Adiciona índices de acervo, conteúdos e calendário, peças por canal com
  `README.md`, frontmatter e IDs, além de comandos de estado e agenda.
- Adiciona capacidades nativas de estratégia, produto, pesquisa de cliente,
  concorrência, oferta, copy, SEO, GEO, CRO, métricas, atribuição,
  experimentação, lançamento, material rico e anti-slop.
- Migra completamente a identidade do pacote, do binário e das skills para
  Inboundfy.

### Documentação

- Atualiza instalação, runtime, catálogo, operação e testes para a separação
  entre framework e projeto consumidor.

## 1.0.0 (2026-07-30)

### Funcionalidades

- Publica o framework e o CLI como o pacote `@promovaweb/inboundfy`.
- Instala metodologia, documentação, ebook, templates e a base inicial de skills.
- Adiciona os comandos `init`, `update`, `repair`, `doctor` e `status`.
- Preserva os arquivos do usuário e customizações encontradas durante reparos.
- Registra hashes SHA-256 dos arquivos gerenciados.

### Documentação

- Inclui o guia completo do usuário em PDF e EPUB.
- Documenta a arquitetura técnica, a instalação e a manutenção do framework.
