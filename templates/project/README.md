# Configuração do Inboundfy

Esta pasta pertence ao projeto consumidor e não ao repositório do framework.

- `framework/` contém a documentação versionada distribuída pelo pacote.
- Os arquivos Markdown na raiz desta pasta guardam dados específicos da empresa.
- `indices/` mantém referências rápidas aos itens criados.
- `migracoes/` recebe cópias de segurança durante atualizações.

Não salve material bruto, peças finais ou dados de calendário aqui. Esses itens
ficam, respectivamente, em `acervo/`, `canais/` e `calendario/`.
